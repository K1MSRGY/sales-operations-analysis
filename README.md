Excel project for sales, inventory and operational data analysis
# Sales Operations Analysis

## Описание проекта

Excel-проект по анализу продаж, товарных запасов и операционных данных.

## Инструменты

- Microsoft Excel
- Формулы Excel
- Data Cleaning
- ABC Analysis
- Data Visualization

## Задачи проекта

- Анализ продаж по товарам
- Анализ показателей по магазинам
- Работа с товарными остатками
- Расчет показателей по заказам
- Поиск и обработка дубликатов
- Очистка и стандартизация справочных данных
- Анализ городов и отраслей
- Формирование ежемесячной отчетности
- Работа с переоценкой товаров

## Использованные инструменты

- IF
- IFERROR
- VLOOKUP
- SUMIFS
- SUMPRODUCT
- COUNTIFS
- Pivot Tables
- ABC Analysis
- Data Cleaning
- Charts

## Результат

Проект демонстрирует использование Excel для комплексной обработки и анализа продаж, товарных запасов и операционных показателей.
